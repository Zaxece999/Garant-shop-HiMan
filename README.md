# Garant Shop HiMan

Telegram-бот на aiogram 3: гарант-сервис для сделок между пользователями плюс встроенный магазин цифровых товаров.

## Возможности

- Гарант-сделки: создание сделки, блокировка суммы на балансе покупателя, подтверждение, комиссия сервиса
- Диспуты с подключением администратора и закрытием сделки в пользу продавца или покупателя
- Отзывы и рейтинг по завершённым сделкам
- Магазин: категории, товары, склад позиций, автоматическая выдача после оплаты, история заказов
- Баланс: пополнение криптовалютой через Heleket (USDT TRC20/ERC20/BEP20, BTC, ETH, LTC), вывод средств
- Реферальная система с процентом от пополнений приглашённых
- Админ-панель: статистика, начисление баланса, рассылки (в том числе отложенные), управление магазином, обработка выводов
- Два языка интерфейса: русский и английский

## Стек

- Python 3.11, aiogram 3.4
- PostgreSQL через peewee-async
- Redis как хранилище FSM
- aiohttp для приёма вебхуков платёжной системы

## Установка

```bash
git clone https://github.com/Zaxece09/Garant-shop-HiMan.git
cd Garant-shop-HiMan
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Нужны запущенные PostgreSQL и Redis. Базу данных создать заранее, таблицы бот создаёт сам при первом запуске.

## Настройка

```bash
cp config.ini.example config.ini
```

Заполнить в `config.ini`:

- `BOT.bot_token` — токен от BotFather
- `DATABASE` и `REDIS` — доступы к базе и Redis
- `CHATS_ID` — ID чатов для логов, заявок на вывод, админских уведомлений и общего чата
- `API_KEYS.heleket` и `WEBHOOK.MERCHANT_ID` — данные мерчанта Heleket
- `LINKS` — ссылки на правила, админа и домен
- `PRICES` и `GARANT` — комиссии и лимиты сделок

Бот должен быть добавлен в указанные чаты и иметь права на отправку сообщений.

## Запуск

```bash
python app.py
```

## Структура

```
app.py                  точка входа, регистрация роутеров
init.py                 конфиг, логгер, база, Redis, объекты бота
tables/                 модели PostgreSQL
telegram/handler/       обработчики: сделки, магазин, баланс, вывод, диспуты, админка
telegram/keyboard/      клавиатуры
telegram/middleware/    защита от параллельных операций
language/               тексты и клавиатуры на ru/en
additional/             утилиты и клиент Heleket API
webhook/                aiohttp-сервер для вебхуков
export_users.py         выгрузка пользователей в CSV
```

## Замечания

`config.ini` содержит ключи и не попадает в репозиторий — он в `.gitignore`. Для деплоя используйте `config.ini.example` как шаблон.
